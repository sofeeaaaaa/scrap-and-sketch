# My Craft Journal

Build a web app that feels like a real-life junk journal. The page should look like a physical journal spread: textured paper background, soft shadows, and slightly imperfect, handmade styling. Core features: - A freeform canvas page where nothing is locked to a grid. Users can place, drag, resize, rotate, and layer (bring forward/send back) any element. - Text boxes that can be placed anywhere on the page and rotated. - Image support: paste images directly from the clipboard (Ctrl/Cmd+V), upload from the device, and drag and drop. Images can be resized, rotated, and cropped, with optional torn-edge or polaroid-style frames. - A decorative toolbar with stickers, washi tape strips, paper scraps, tickets, stamps, and doodles the user can add and layer. - Multiple pages with a page-turning animation, plus the ability to add, delete, and reorder pages. - Different paper backgrounds to choose from (lined, graph, kraft, vintage, torn notebook paper). - Autosave everything in the browser, with an option to export pages as images or PDF. Design feel: warm, cozy, tactile, scrapbook-like. Not a clean corporate UI. Toolbars should look like a desk of craft supplies and stay out of the way of the page.
